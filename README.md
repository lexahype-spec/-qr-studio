# QR Studio — генератор QR-кодов с историей

Учебный веб-проект на Flask. Позволяет создавать QR-коды из текста или ссылки, скачивать PNG, сохранять историю генераций, повторно скачивать и удалять записи.

## Требования
- Python 3.9+
- pip

## Запуск Windows
1. Распакуйте архив в отдельную папку.
2. Откройте терминал (CMD или PowerShell) в папке проекта.
3. Установите зависимости:
   ```bash
   py -m pip install -r requirements.txt
   ```
4. Запустите сайт:
   ```bash
   py app.py
   ```
5. Откройте в браузере:
   http://127.0.0.1:5000

При первом запуске создаётся SQLite-файл `qr_history.db`.

## Запуск macOS / Linux
```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

## Основные функции
- QR-код из текста или ссылки
- Скачивание изображения в PNG
- Сохранение истории в SQLite
- Повторное скачивание
- Удаление записей

## Структура
- `app.py` — Flask-приложение и маршруты
- `templates/index.html` — страница сайта (Jinja2)
- `static/style.css` — оформление
- `requirements.txt` — зависимости
- `qr_history.db` — база данных (создаётся при запуске)

> Для публичного размещения рекомендуется отключить debug-режим, задать секретный ключ через переменную окружения и добавить CSRF-защиту.
